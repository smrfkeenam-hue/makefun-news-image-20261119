A one-page newspaper front page summing up the world news of Thursday 19 November 2026, drawn programmatically in pure Python (standard library only) and written to `/output/entry.png`. The masthead names the day; the lead story is the first-ever U.S.-China-Russia trilateral summit in Shenzhen, and four panels cover gold crashing below $3,700 on hawkish Fed minutes, the Houthi missile strike on Riyadh's PIF Tower, Europe's Ukraine summit in Berlin, and the U.S.-China trade truce extension. All text is rendered with an embedded 5x7 pixel font, so it stays crisp and legible — no garbled glyphs. Every run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
